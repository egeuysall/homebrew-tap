# egeuysall Homebrew tap

```sh
brew tap egeuysall/tap
brew install --formula egeuysall/tap/bri egeuysall/tap/ibx egeuysall/tap/zap
```

Homebrew updates the formulae from this tap every six hours. Installed CLIs use
Homebrew for `self-update`; the normal upgrade command is:

```sh
brew update && brew upgrade --formula bri ibx zap
```
